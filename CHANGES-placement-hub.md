# Placement Hub (new)

Sidebar / mobile nav → **Placement Hub** (`activeScreen = 'placement_hub'`). 5 tabs:

1. **Placement Companies** – 34 regional companies (Uttarakhand, Delhi-NCR, nearby cities) from
   `lib/data/regionalCompaniesData.ts`. Each card shows the first line of every detail; **Read more**
   opens the full profile. A second view shows GPT Tanakpur's 2021-26 placement record + charts
   (`lib/data/campusPlacementStats.ts`, from placement_details_2026_charts.xlsx).
2. **Interview Q&A** – existing 260+ question bank + company-wise questions.
3. **Resource Library** – placement resources + Placement Club plan + existing academic library.
4. **Quiz Stats** – accuracy ring + counts (now really updated by the govt-exam quiz).
5. **Mentorship Booking** – date/slot/mode form, "My bookings" list with cancel (saved in the browser).

Salary numbers in company profiles are indicative – verify on official career pages before sharing with students.
